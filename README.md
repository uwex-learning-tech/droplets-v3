# DROPLETS
**version 3.5.0**  

A HTML, CSS, and JavaScript framework for Instructional Designers at Office of Online & Professional Learning Resources (OPLR).

### How To Use
1. To start, download the [framework](https://github.com/uwex-learning-tech/droplets-v3/archive/master.zip) (ZIP).
2. Unzip or extract the ZIP file when the download is completed.
3. Open the `dist` folder.
4. Inside the `assets` folder, upload the `droplets.css` and `droplets.js` files to your LMS's theme.
5. Inside your LMS's WYSIWYG (or rich content) editor, wrap your HTML inside a `div` tag with ID of `uws-droplets-page`.

**Note:** This framework is specifically developed for use by Instructional Designers at OPLR. Some setups or usages may not be optimal or preferable for your organization. In addition, this framework is built to accommodate the Canvas LMS. You are most welcome to download or fork this repository and modify it to fit your organization's needs.

### Development Requirements
* Node.js 22.15 or later, with NPM
* Webpack version 5 or later
* HTML
* Cascading Style Sheets (CSS3)
* SASS (http://sass-lang.com/)
* JavaScript

### Recommended Web Browsers

* Google Chrome

* Apple Safari
* Opera

*Latest stable version is always recommended.*
